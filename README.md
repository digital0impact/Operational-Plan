# منصة الخطة التشغيلية

منصة لإعداد الخطة التشغيلية لمدارس التعليم العام، مبنية على «دليل إجراءات
عمل مدارس التعليم العام 2025م» (رمز الإجراء س-1-أ-1) لإعداد الخطة التشغيلية
1447-1448هـ.

خطة المعمار الكاملة (نموذج البيانات، رحلة المستخدم، خارطة الطريق) منشورة
كوثيقة تصميم منفصلة، وهذا المستودع ينفّذ معالج الخطة التشغيلية **الكامل من
25 خطوة**: تسجيل مدرسة برمز تفعيل، تسجيل الدخول، ولوحة المدرسة.

## الحالة الحالية

- ✅ تسجيل مدرسة جديدة برمز تفعيل (`SCH-XXXX-XXXX`) وتسجيل دخول مدير المدرسة
- ✅ لوحة المدرسة: نسبة الإنجاز، ملخص بيانات المدرسة، حالة كل خطوة من الـ 25
- ✅ المعالج الكامل (`/wizard/1` … `/wizard/25`):
  - **1–4 الإعداد والبيانات** — بيانات المدرسة، مستوى الأداء، مدخلات
    الإجراء، مراجعة واعتماد
  - **5–6 الارتباط الاستراتيجي** — عرض الأهداف الاستراتيجية العشرة الثابتة،
    وصياغة هدف تشغيلي مقابل لكل واحد منها
  - **7–8 مؤشرات الأداء** — مؤشر قياس أداء وقيمة مستهدفة لكل هدف تشغيلي
  - **9–12 تحليل SWOT** — قوة / ضعف / فرص / تهديدات (قوائم قابلة للإضافة
    والحذف)
  - **13 القضايا الرئيسية**
  - **14–15 المبادرات والبرامج** — لكل هدف تشغيلي من العشرة
  - **16–25 الخطة التفصيلية** — خطوة واحدة لكل هدف استراتيجي: الأنشطة،
    الفئة المستهدفة، متطلبات التنفيذ، تاريخ التنفيذ، التنفيذ والمسؤولية،
    الشواهد — لكل مبادرة/برنامج تحت ذلك الهدف
- ✅ تصدير PDF بتنسيق A4 عربي مطابق لبنية الدليل الرسمي (`/export`): الغلاف،
  بيانات المدرسة ومستوى الأداء ومدخلات الإجراء، مصفوفة الأهداف
  الاستراتيجية/التشغيلية، مؤشرات الأداء وتحليل SWOT، القضايا والمبادرات
  والبرامج، ثم الخطة التفصيلية الكاملة لكل هدف استراتيجي
- ⏳ التصويت على البرامج، رابط المشاركة والتقييم، لوحة الإدارة العامة
  (إصدار رموز التفعيل)، تكامل الذكاء الاصطناعي — إصدارات لاحقة

## المكدّس التقني

- **Next.js 16** (App Router، Server Actions، Turbopack، مسار معالج ديناميكي
  `wizard/[step]`)
- **Prisma ORM 7** + SQLite (عبر `@prisma/adapter-better-sqlite3`) للتطوير
  المحلي — قابل للتبديل إلى PostgreSQL لاحقًا بتغيير `provider` في
  `prisma/schema.prisma` ومحوّل الاتصال في `src/lib/db.ts`
- **Tailwind CSS v4** (نمط RTL كامل، لوحة ألوان تيل/كهرماني)
- **Zod** للتحقق من صحة المدخلات
- جلسات مصادقة مخصّصة (جدول `Session` + كوكي HttpOnly، بدون مكتبة خارجية)
  وتجزئة كلمات المرور عبر `scrypt` المدمجة في Node.js
- **تصدير PDF**: قالب HTML مخصّص (`src/lib/pdf/template.ts`) يُعرَض عبر
  Chromium الخالي من الواجهة (`playwright-core`)، مع خط Noto Naskh Arabic
  مُضمَّنًا كـ base64 داخل الصفحة نفسها حتى لا يعتمد الإخراج على خطوط عربية
  مثبَّتة على الخادم

## التشغيل محليًا

```bash
npm install
npx prisma migrate dev   # ينشئ dev.db ويطبّق المخطط
npx prisma db seed       # يزرع الأهداف الاستراتيجية العشرة + رمز تفعيل تجريبي
npm run dev
```

افتح `http://localhost:3000/register` واستخدم رمز التفعيل التجريبي الذي
تمت طباعته من أمر `db seed` (افتراضيًا `SCH-DEMO-0001`).

### تصدير PDF في بيئة أخرى غير هذه البيئة التطويرية

يعتمد `/export` على وجود تنفيذي Chromium على القرص (لا يُنزَّله
`playwright-core` تلقائيًا). في هذه البيئة يتوفر مسبقًا على
`/opt/pw-browsers/chromium`. في بيئة إنتاج أخرى ثبِّت Chromium (أو استخدم
حزمة مثل `@sparticuz/chromium` في بيئة serverless) واضبط متغيّر البيئة:

```bash
PDF_CHROMIUM_PATH=/path/to/chromium
```

## بنية المشروع

```
prisma/schema.prisma        نموذج البيانات الكامل (School, User, Session, ActivationCode,
                             StrategicGoal, OperationalGoal, KPI, SwotItem, KeyIssue,
                             InitiativeProgram, ActionItem, ProcedureInput, WizardStepProgress)
prisma/seed.ts               زراعة الأهداف الاستراتيجية العشرة + رمز تفعيل تجريبي
src/lib/                     قاعدة البيانات، الجلسات، تجزئة كلمات المرور، القوائم الثابتة،
                              استعلامات المعالج المشتركة (wizard-data.ts)
src/app/actions/             Server Actions (تسجيل/دخول/خروج، حفظ كل خطوات المعالج الـ 25)
src/app/(app)/dashboard/     لوحة المدرسة
src/app/(app)/wizard/[step]/ المعالج الكامل — صفحة ديناميكية واحدة توزّع المحتوى حسب رقم الخطوة
src/app/(app)/export/        نقطة تصدير PDF (Route Handler)
src/components/wizard/       مكوّنات كل مجموعة خطوات (الأهداف، SWOT، المبادرات، الجدول التفصيلي)
src/lib/pdf/                 قالب HTML لخطة PDF (template.ts)، تضمين الخط العربي (fonts.ts)،
                              ومحرّك التصيير عبر Chromium (render.ts)
src/assets/fonts/            خط Noto Naskh Arabic المُضمَّن في PDF
src/app/login, src/app/register   بوابة الدخول الموحدة
src/proxy.ts                  حماية المسارات المحمية وإعادة التوجيه
```

## نموذج البيانات المختصر

- `StrategicGoal` (10 أهداف ثابتة، بيانات مشتركة) ← `OperationalGoal`
  (واحد لكل مدرسة لكل هدف استراتيجي) ← `KPI` (مؤشر + قيمة مستهدفة واحدة)
  و`InitiativeProgram[]` (عدة مبادرات/برامج) ← `ActionItem` (تفاصيل التنفيذ
  لكل مبادرة/برنامج)
- `SwotItem` و`KeyIssue` بيانات مستوى-المدرسة (غير مرتبطة بهدف معيّن)
- `WizardStepProgress` يسجّل إتمام كل خطوة من الـ 25 لكل مدرسة، ويُستخدم في
  حساب نسبة الإنجاز في لوحة التحكم
